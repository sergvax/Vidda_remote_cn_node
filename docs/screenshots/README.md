# Скриншоты

| Файл | Что показано |
|---|---|
| `remote-ui.png` | Веб-пульт на ширине 442 px (мобильная раскладка): ползунок громкости и блок «Избранное». |
| `projector-home.jpg` | Домашний экран проектора: HDMI 1 / HDMI 2 и плитки приложений. |
| `projector-settings.jpg` | Меню проектора, открытое командой `KEY_SETTING`. Виден пункт `Auto Focus`. |

Скриншоты проектора сделаны через MQTT-действие `screenshot`, а не камерой.
Это же действие использует кнопка с камерой в интерфейсе пульта. У сервиса есть
лимит частоты: после серии быстрых снимков он на несколько минут отдаёт пустой
ответ, поэтому в пульте снимок обновляется вручную.

На скриншотах скрыты IP-адрес, имя устройства и системная строка состояния
проектора. Снимков с видео в репозитории нет.
